# Frontier DLNA Fix – Home Assistant add-on

Makes Frontier Silicon radios whose DLNA description lacks a `serviceList`
(e.g. Kenwood CR-ST100S) usable in Music Assistant.

## Install

1. Settings → Add-ons → Add-on Store → ⋮ → Repositories
2. Add `https://github.com/twesio/ha-frontier-dlna-fix`
3. Install **Frontier DLNA Fix**, set `radio_host` on the Configuration tab, start it.

See [DOCS.md](frontier_dlna_fix/DOCS.md) for details.
